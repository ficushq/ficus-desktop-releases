# Ficus Desktop downloads

Signed and notarized Ficus Desktop builds for Apple Silicon Macs.

Download the latest app from [ficus.sh](https://ficus.sh/download/desktop/macos) or from [Releases](https://github.com/ficushq/ficus-desktop-releases/releases). Quit the old app before replacing it. Your selected Ficus data home is separate from the application.

`updates/ficus-darwin-arm64.json` is Ficus Desktop's auto-update feed. Only signed, notarized releases are promoted there, after the upload is verified. `updates/darwin-arm64.json` is the feed of the retired Tau Desktop app: it stays at its last release and tells Tau Desktop users to install Ficus Desktop.

Ficus: https://ficus.sh
